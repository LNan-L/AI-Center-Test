# AI-Center 测试 · 星空战舰动态演示

> 零依赖、单文件的前端 **Canvas 2D** 实时演示：视差星空、超空间跃迁、炮塔自动交战、全套 HUD 与 WebAudio 实时合成音效。

`HTML` · `CSS` · `JavaScript` · `Canvas 2D` · `WebAudio` · 无框架 · 无构建 · 无外部资源

---

## 项目简介

本项目是 **AI-Center 测试**系列的第一个演示工程，用于验证「纯前端单文件」能否承载一个高帧率的实时科幻场景。

打开 `star-warship.html` 即可运行 —— 不需要服务器、不需要 npm、不需要任何网络请求。所有视觉元素（星空、星云、战舰、敌机、爆炸、护盾）都是 **程序化绘制** 的矢量图形，所有音效都是 **WebAudio 实时合成** 的，仓库内不存在任何图片或音频素材。

## 快速开始

```bash
# 方式一：直接双击（推荐）
star-warship.html

# 方式二：本地静态服务
python -m http.server 8080
# 然后访问 http://127.0.0.1:8080/star-warship.html
```

浏览器要求：任意现代浏览器（Chrome / Edge / Firefox / Safari），无需插件。

## 操作说明

| 操作 | 效果 |
| --- | --- |
| 移动鼠标 / 触摸拖动 | 指挥舰队：星空与舰体视差偏移、舰体轻微滚转 |
| 单击画面 / `空格` | 超空间跃迁（3.2 秒冷却） |
| `C` | 自动巡航开 / 关 |
| `F` | 全炮塔齐射 |
| `M` | 音效开 / 关 |
| 底部按钮 | 跃迁 · 自动巡航 · 开火 · 音效 · 全屏 |

> 浏览器策略要求音频必须由用户手势触发，因此音效默认为**关闭**，点「音效」或按 `M` 才会启动。

## 画面构成

| 模块 | 实现要点 |
| --- | --- |
| **视差星空** | 5 层深度，逐层控制速度、亮度、尺寸；每颗星有独立闪烁相位；跃迁时沿运动方向拉成光条 |
| **星云** | 离屏 `canvas` 预渲染（多组径向渐变 + 内嵌星尘），运行时加法混合慢速漂移与自转 |
| **战舰** | 程序化矢量舰体：装甲分块斜纹、中央脊线、舰桥窗灯、三组引擎尾焰、能量舰首、5 座随动炮塔 |
| **超空间跃迁** | 星空拖尾 + 环向隧道射线 + 全屏泛光 + 冲击波 + 镜头震动，五层叠加 |
| **交战系统** | 敌机成波次来袭（大小两种血量），炮塔自动索敌、弹道命中判定、火花、爆炸粒子、冲击波 |
| **护盾** | 双层椭圆弧光 + 随威胁度点亮的六边形网格 |
| **HUD** | 四角框线、速度（1.0c → 27c）、护盾 / 舰体 / 威胁条、FPS 与星数、扫描线、暗角 |
| **音效** | WebAudio 实时合成：引擎低鸣（3 路失谐锯齿 + 低通）、激光（扫频方波）、爆炸（噪声 + 低通包络）、跃迁（扫频带通） |

## 工程特性

- **单文件交付**：HTML / CSS / JS 全部内联，便于分发与嵌入
- **零依赖**：无第三方库、无字体文件、无图片、无音频素材
- **自适应分辨率**：`devicePixelRatio` 上限 2；星星数量按视口面积在 700–4200 之间自适应
- **自动降级**：FPS 持续低于 42 时，逐步跳过最远星空层、关闭近景尘埃
- **防抖重建**：窗口 `resize` 220ms 防抖，避免移动端反复重建星云造成卡顿
- **热点优化**：星云预渲染、近景尘埃不使用逐帧渐变对象、跃迁拖尾改用加法混合描边
- **全套键盘操作**：不依赖鼠标也能完成跃迁、巡航、开火、音效全部操作
